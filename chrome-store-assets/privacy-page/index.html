Privacy at a glance: Epsilon processes download and webpage information only to provide download-manager features. It does not operate an analytics or advertising service, sell user data, or send browsing data to the developer's servers.

1. Scope and purpose

This Privacy Policy explains how the Epsilon Download Manager Chrome extension (the “Extension”) and its connection to the locally installed Epsilon Download Manager Windows application (the “Desktop App”) handle information.

The Extension’s single purpose is to let users capture browser downloads, selected links, webpage links and downloadable media, then manage those downloads in the Desktop App. The Extension communicates with the Desktop App through Chrome Native Messaging on the same computer.

2. Information the Extension handles

Epsilon handles only the information reasonably required for its user-facing download features:

Download information
Download URLs, suggested filenames, MIME/content type, file size, referrer and download status are used to create and manage downloads requested by the user.
Web history data
The active page URL and title, and URLs of resources associated with that page, are processed to identify the correct page, name media and present download choices. Epsilon does not build or transmit a general browsing-history profile.
Website content
Links, link labels and media metadata from the current page are processed when showing downloadable media or when the user requests selected/all links.
Authentication information
Cookies matching a requested download or media URL may be used so downloads that require the user’s existing website session can continue in the Desktop App. The Extension does not read or request passwords.
User activity
Network response metadata, tab navigation and clicks on Epsilon controls are processed to detect downloadable resources, keep results attached to the correct tab and perform actions explicitly requested by the user.
Preferences
Capture on/off, excluded sites, language, theme and recent connection-error information are stored locally to provide the selected behavior.
No developer-server collection. The Extension does not send this information to Epsilon’s developer, analytics providers or advertising services. Requested download information is transferred through Native Messaging to the Desktop App on the same computer. The requested download server will receive the normal network request and any authentication cookie required for that download.

3. Use and sharing

The information above is used only to provide or maintain Epsilon’s download features: capturing downloads, detecting downloadable media, collecting links selected by the user, naming files, authenticating requested downloads and communicating with the Desktop App.

  • Epsilon does not sell user data.
  • Epsilon does not use user data for advertising, profiling, creditworthiness or lending.
  • Epsilon does not transfer user data to third parties except when necessary to contact a download server selected by the user, to comply with law, or to protect against security abuse.
  • No human reviews a user’s browsing or download information unless the user deliberately provides specific information for a support request.

Chrome Web Store Limited Use disclosure: The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

4. Chrome permissions

  • contextMenus: provides right-click commands for links, media and selected/all page links.
  • downloads: detects browser downloads and transfers accepted downloads to Epsilon; the browser copy is cancelled only after the Desktop App accepts it.
  • nativeMessaging: communicates with the locally installed Desktop App.
  • cookies: obtains cookies relevant to a requested download so authenticated downloads can work.
  • webRequest: observes resource URLs and response metadata to detect downloadable media.
  • storage: saves local preferences, temporary media results and recent connection errors.
  • scripting: collects links selected by the user in the active page or frame.
  • tabs and host access: associates media and link results with the correct HTTP/HTTPS page and supports downloads from websites chosen by the user.

All executable code is included in the Extension package. The Extension does not download or execute remote JavaScript or WebAssembly.

5. Local storage, security and retention

Per-tab media results are temporary and are cleared when the tab navigates or closes. Extension preferences remain in Chrome’s local extension storage until changed, cleared or the Extension is removed.

The Desktop App may retain download records and information required to pause or resume a download until the user removes them. If a cookie must be persisted for an unfinished download, the Desktop App protects it locally using Windows data-protection facilities. Diagnostic reports are created only when the user requests one and are not uploaded automatically.

Native Messaging transfers between the Extension and Desktop App remain on the same computer. Network downloads use the protocol provided by the user’s chosen download server; users should prefer HTTPS sources for sensitive downloads.

6. Your choices and controls

  • Turn browser-download capture off from the Extension popup.
  • Add websites to the exclusion list.
  • Choose whether to send selected links, all links or individual media.
  • Clear Extension storage or uninstall the Extension in Chrome.
  • Remove download history and application data using Epsilon’s controls or Windows application settings.

7. Changes to this policy

This policy may be updated when Epsilon’s features, permissions or legal obligations change. The effective date at the top of this page will be updated. Material changes to data practices will also be disclosed in the Extension or its Chrome Web Store listing before the changed handling begins.

8. Contact

Questions, privacy requests and security reports can be sent to epsilondownloadmanager@gmail.com.

افزونهٔ اپسیلون برای انتقال دانلودهای مرورگر، لینک‌های انتخاب‌شده، لینک‌های صفحه و رسانه‌های قابل دانلود به برنامهٔ ویندوز Epsilon Download Manager استفاده می‌شود. ارتباط افزونه و برنامه از طریق Native Messaging و روی همان رایانه انجام می‌شود.

اطلاعاتی که پردازش می‌شوند

  • نشانی دانلود، نام فایل، نوع و اندازهٔ فایل، ارجاع‌دهنده و وضعیت دانلود
  • نشانی و عنوان صفحه و اطلاعات لینک‌ها یا رسانه‌های همان صفحه
  • کوکی مرتبط با لینک دانلود، فقط زمانی که برای ادامهٔ دانلود واردشده لازم باشد
  • تنظیمات محلی افزونه مانند زبان، پوسته، روشن/خاموش بودن دریافت دانلود و سایت‌های مستثنا

این اطلاعات به سرور سازنده، سرویس تبلیغاتی یا سرویس تحلیل آماری ارسال نمی‌شود. اطلاعات لازم برای دانلود فقط به برنامهٔ Epsilon نصب‌شده روی همان رایانه منتقل می‌شود. اپسیلون اطلاعات کاربران را نمی‌فروشد و برای تبلیغات، پروفایل‌سازی یا اعتبارسنجی مالی استفاده نمی‌کند.

نتایج موقت رسانه با بسته‌شدن یا تغییر صفحه پاک می‌شوند. تنظیمات تا زمانی که کاربر آن‌ها را تغییر دهد یا افزونه را حذف کند روی مرورگر باقی می‌مانند. اطلاعات لازم برای ادامهٔ دانلود ممکن است توسط برنامهٔ ویندوز و با حفاظت اطلاعات ویندوز نگهداری شود.

استفاده از اطلاعات دریافت‌شده از APIهای گوگل مطابق سیاست دادهٔ کاربران Chrome Web Store و الزامات Limited Use خواهد بود.
