Epsilon Download Manager - adding the browser extension
=====================================================

Epsilon is already connected to Chrome, Edge, Brave and Firefox by the installer. What is left is to switch the extension on
in the browser once (browsers do not allow a program to do this silently).

Chrome / Edge / Brave
  1. Open  chrome://extensions   (Edge: edge://extensions,  Brave: brave://extensions)
  2. Turn on "Developer mode".
  3. Click "Load unpacked" and choose the folder  browser-extension  inside the Epsilon folder
     (Start menu > Epsilon Download Manager - browser extension folder).
  4. Close and reopen the browser, click the Epsilon icon on the toolbar: it should say "Connected".

Firefox
  1. Open  about:debugging#/runtime/this-firefox  and click "Load Temporary Add-on...".
  2. Choose  browser-extension-firefox\manifest.json  in the Epsilon folder.
  Firefox removes temporary add-ons when it closes. For a permanent install use Firefox Developer Edition or ESR
  (about:config > xpinstall.signatures.required = false) and open extension-packages\epsilon-firefox.zip renamed to .xpi.

Something not working?  Start menu > "Epsilon Download Manager - check the browser connection" shows what is wrong.

YouTube and other protected sites
  Open Epsilon > Options > "YouTube & other sites" > "Download / update tools" once.
