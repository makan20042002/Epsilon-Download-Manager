# Makan Download Manager V9.1 — Final Cleanup

## Code quality
- Cleaned the download orchestration path and made segmented downloads cancellation-safe.
- Sibling range requests are now cancelled and awaited before partial segment cleanup after a failure.
- Added repository-wide `.editorconfig` conventions.
- Added deterministic build properties through `Directory.Build.props`.
- Kept nullable reference types and modern C# language settings enabled.

## Download engine
- Adaptive connection count based on server capabilities and object size.
- HTTP range probing with HEAD fallback to a byte-range GET probe.
- ETag / Last-Modified validation for resumable downloads.
- Retry and exponential backoff.
- Global and per-download bandwidth limiting.
- Atomic finalization and SHA-256 verification.
- Crash recovery of interrupted jobs.

## Browser

- Context menu and download interception.
