# V7.1 Clean / Debug Release

## Fixed
- Native browser acknowledgement no longer depends on a long-lived native-host process.
- Browser requests are forwarded to the running desktop app through a named pipe.
- If the desktop app is closed, the bridge starts a hidden background instance before forwarding the request.
- Segmented progress is aggregated atomically.
- Resume validates remote ETag/Last-Modified when available.
- Single-connection resume uses If-Range.
- Range failures fall back to a clean single-connection download.
- Retry/backoff added for transient network failures.
- Final file length is checked against the expected content length.
- SHA-256 verification remains supported.
- FFmpeg arguments now use ProcessStartInfo.ArgumentList instead of manual quoting.
- Browser context-menu creation is made update-safe.
- Relative browser filenames are sanitized and stored in the user's Downloads folder.
- Crash recovery requeues interrupted downloads.
- History records distinct start/finish timestamps.

## Deliberate scope
The app does not attempt DRM bypassing or protected-stream extraction. HLS/DASH support is a normal FFmpeg handoff.
