Epsilon Download Manager is a fast, private download manager for Windows 10/11, built with WPF on .NET 8, with browser integration for Chrome, Edge, Brave, and Firefox. Nothing ever starts by itself — you always choose Start Download or Download Later.

Key features:

Resumable downloads — up to 16 connections per file, exact-byte resume after pause/crash/restart, retry with back-off, a global speed limiter, and SHA-256 checksum verification.
BitTorrent support — magnet links and .torrent files, DHT/PEX, per-file priority, seeding with ratio/time limits.
Video downloading — native HLS (.m3u8) and DASH (.mpd) support, plus YouTube and other protected sites via yt-dlp.
Smart connection handling — automatically backs off on servers returning 429/503 and remembers this between sessions.
Browser integration — cookie/referrer-aware downloads, "download this video" button, batch link capture, keyboard shortcuts.
IDM-style UI — categorized queue, scheduler, batch downloads, site grabber, drop target, and an "Intelligent Center" dashboard with health checks and bandwidth profiles.
Privacy-first — encrypted cookie storage (Windows DPAPI), no cross-site cookie leakage, HTTPS-only updates with SHA-256 verification.
Localization — English and Persian (فارسی) with RTL support, light/dark themes, and portable mode.
