# Epsilon Download Manager — directory listing copy

## Short description

A fast, private, open-source download manager and BitTorrent client for Windows.

## Long description

Epsilon Download Manager is a free and open-source Windows download manager built for reliable everyday downloads. It supports segmented HTTP and HTTPS transfers, pause and resume, queues and scheduling, per-file and combined speed limits, browser integration, video capture, download verification, Multi-Net downloads, and BitTorrent transfers. Epsilon keeps download management on the user's computer and includes official browser extensions for Chrome-family browsers and Firefox.

## Main features

- Segmented HTTP and HTTPS downloads with pause, resume, retries, and recovery
- BitTorrent and magnet-link support
- Queues, schedules, simultaneous-download controls, and speed limiting
- Chrome Web Store and Firefox Add-ons integrations
- Video detection and capture with download-quality choices
- SHA-256 verification and privacy-focused local operation
- English and Persian interfaces with multiple themes
